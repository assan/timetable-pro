Проект по оптимизацции расписания автошколы. Составляется расписание с максимально возможным количеством занятий, учитывая ограничения по свободному времени курсантов и инструкторов. Веб-интерфейс написан порседством Djando на Python. Для решение задачи оптимизации используется модель линейного программирования.
