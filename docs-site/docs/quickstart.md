# Быстрый старт

В этом разделе показано, как за несколько минут составить расписание.

1. **Авторизуйтесь** в системе (логин и пароль администратора).
2. **Добавьте учеников** — укажите имя и доступные для них дни/часы.
3. **Добавьте инструкторов** — укажите расписание и автомобили.
4. **Нажмите "Составить расписание"**. 

✅ Всё! У вас есть первое расписание.
