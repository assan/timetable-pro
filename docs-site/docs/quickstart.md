# 🚀 Быстрый старт

В этом разделе показано, как за **5 минут** составить первое расписание.

---

## Шаги

1. **🔑 Авторизуйтесь в системе**
   Используйте логин и пароль администратора.

2. [**👨‍🎓 Добавьте учеников**](https://www.loom.com/share/5494ecc05f7b4951a7371dca5e2dd3a6?sid=38296c6e-e599-4a49-b797-4c16e273b2cd)  
   Укажите имя и доступные для них дни/часы.

3. [**🚗 Добавьте инструкторов**](https://www.loom.com/share/be893a839ee54c099f4995de495556e8?sid=9d28ddf6-c0a3-4714-8f74-667886d21fcb)  
   Укажите расписание и автомобили.

4. [**📅 Нажмите "Составить расписание"**](https://www.loom.com/share/5132ec65412b468480afa4b213c930bc?sid=6941d618-0f8b-4790-be54-62ae85688ffb)  
   Система автоматически создаст расписание.

---

✅ Поздравляем! Первое расписание готово 🎉
