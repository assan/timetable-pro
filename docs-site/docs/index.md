# Обзор программы

Эта программа помогает автоматически составлять оптимальное расписание занятий
для курсантов автошколы.

## Возможности
- Автоматическая генерация расписания
- Учёт инструкторов и учеников
- Ручное редактирование

➡ Перейдите к разделу [Быстрый старт](quickstart.md), чтобы за 5 минут создать первое расписание.
